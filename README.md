# 🌱 Praeda

Aplicación web desarrollada en **PHP** como proyecto de grado de educación media, orientada a promover la educación y la concienciación sobre el cuidado del medio ambiente. El sistema integra funcionalidades de gestión de contenido, autenticación de usuarios y administración de información mediante una arquitectura basada en PHP y MySQL.

> **Nota:** Este proyecto fue desarrollado varios años antes de mi formación universitaria. Aunque no refleja las prácticas de desarrollo y diseño de software que utilizo actualmente, constituye una muestra de mis primeros proyectos de desarrollo web y de mi evolución como desarrollador.

---

## 📖 Descripción

Praeda fue concebido como un proyecto colaborativo para el trabajo de grado del colegio, con el propósito de ofrecer una plataforma web enfocada en la difusión de información y la gestión de contenidos.

El proyecto permitió aplicar conocimientos de desarrollo web utilizando PHP, HTML, CSS, JavaScript y MySQL, abordando aspectos como autenticación de usuarios, interacción con bases de datos y administración de contenido.

---

## ✨ Funcionalidades

* Registro e inicio de sesión de usuarios.
* Administración de usuarios.
* Gestión de contenido.
* Conexión con base de datos MySQL.
* Paneles de administración.
* Navegación mediante múltiples módulos del sistema.
* Interfaz web desarrollada con HTML, CSS y JavaScript.

## 🏛️ Arquitectura

El proyecto sigue una arquitectura tradicional de aplicaciones web desarrolladas en PHP.

Su estructura se organiza mediante diferentes módulos encargados de:

* Gestión de usuarios.
* Conexión a la base de datos.
* Administración del contenido.
* Interfaces para usuarios y administradores.

Aunque la organización del código responde a las prácticas habituales del momento en que fue desarrollado, representa una base importante en mi proceso de aprendizaje del desarrollo web.

## 🚀 Instalación

1. Clonar el repositorio.

```bash
git clone https://github.com/Miguel-Cerquera/Praeda.git
```

2. Copiar el proyecto al directorio del servidor web.

3. Crear la base de datos correspondiente en MySQL e importar el script SQL incluido en el proyecto (si aplica).

4. Configurar las credenciales de conexión a la base de datos.

5. Iniciar Apache y MySQL y acceder a la aplicación desde el navegador.
